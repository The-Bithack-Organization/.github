# --- THE BITHACK ORGANIZATION ---
## "Hack The Planet"
The Bithack Organization is a development group based around making tools for 2017 Hacking MMO '[Grey Hack](https://store.steampowered.com/app/605230/Grey_Hack/)'
Our main project is Bithack - a tool made using Grey Hacks Scripting API '[GreyScript](https://documentation.greyscript.org/)' designed to find and use exploits to gain access to in-game machines owned by both Players and NPCs.
The aim for Bithack is to provide a highly customisable, advanced, user-friendly tool that is easy for newer players and capable for experienced players.
The way we want to achieve this is by Bithack Extensions.
By itself, Bithack can do things like capturing network packets to find passwords and connect to the network, scan a system remotely or locally to locate exploits and gain shells, and connect to routers.
However, if users require a larger library of tools, Bithack has support for installing binaries that 'extend' Bithack. From custom startup animations to extra commands, Bithack can cover it.
Extensions that are planned for release alongside Bithack and are in development include:
- BitCMD, advanced shell for Bithack - the 'true hacker' extension, providing batching and more!
- BitAegis, a fork of the Grey-Hack Defense Initiatives (GDI) Aegis defense program, designed for user-security and system monitoring.
